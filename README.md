# توانا | ابزارهای هوش مصنوعی برای مربیان

این مخزن شامل منابع آموزشی درباره ابزارهای هوش مصنوعی برای مربیان و مدرسان است.

### 📚 منابع آموزشی

- **BM1:** فایل ارائه پاورپوینت
- **BM2:** فایل‌های پاورپوینت و PDF

### 🎯 هدف
کمک به مربیان و مدرسان برای آشنایی با ابزارهای هوش مصنوعی و کاربرد آن‌ها در آموزش.

### 📥 دریافت منابع
برای مشاهده یا دانلود فایل‌ها، از بخش فایل‌های همین مخزن استفاده کنید.
